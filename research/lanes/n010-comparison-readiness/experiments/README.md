reference acquisition and GPU validation. Implementation identities and state
hashes are locked before their corresponding acquisitions. Any amendment is
dated and prospective; failed or diagnostic runs remain in the record.

[039 — operational CPU-budget continuation](039-operational-cpu-budget-continuation.md)
was registered in `5add08f` on 2026-10-15 before the new capability witness and
boundary monitor. It changes fresh-process offline CPU scheduling only, retaining
the same complete own prefixes, all statistical gates and the fixed sample cap.

[040 — light-surface reference proposal](040-prospective-light-surface-reference-sampling.md)
is a separate prospective CPU sampling candidate. It preserves the transport
integral and current acquisitions; physical/prefix proofs and a bounded
feasibility screen precede any subsequent reference-admission transition.

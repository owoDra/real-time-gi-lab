# N006 P1m0 — primary-hit → composite-probe consumer coverage (FROZEN, SOURCE-LEVEL)

Issue #42; 2026-10-11. **No GPU measurements or P1 predictor validation yet.** Follows P1a–P1c influence/duplicate-input observations and P1j canonical probe×cascade work. The separate P1l-C0 E003 software traversal investigation remains a performance sub-study, *not* the original N006 predictive allocation goal.

## Precisely stated uncertainty

- P1a 11/12 owner-local four-ray interventions had exactly zero changed final-image pixels; one changed 468 other pixels but not its source tile. P1b proved a zero-final-image cascade-0 intervention nevertheless changed the stored integer accumulator by one; 151-owner shared cascade-3 key was diluted, yet influenced 468 other pixels. This does not establish why cascade 0 affected no pixels.
- Current composite shader reconstructs screen-pixel **world hit position from primary hit distance and camera**, then for each cascade computes `floor((position - scene_origin)/spacing)` and reads `lookup_probe` for key `(probe_x,probe_y,probe_z,cascade)`.
- Source-level **candidate diagnostic**: count the number of valid primary pixels that *would attempt to read* each such key. This is **key-lookup coverage**, not evidence of an actual storage hit (frame id/key/hash can still miss), not a derivative of global RMS gain, and not a predictive marginal-gain score by itself. It is obtainable after primary visibility and **before** secondary tracing *if* the runtime scheduling/ownership permits a GPU pass then; the first probe is post-frame, diagnostic only.

Distinguish invalid numeric key, valid key not in canonical table, bounded hash lookup failed, successful lookup, per-key uint32 overflow, and GPU work dispatch/initialization failures. Guard `capacity` and `max_probe`; never extend probing without a frozen new protocol.

## Source control, integrity and STOP

- Existing `n001_composite.comp.glsl` uses source-exact pixel position:
  `nx=(2*(float(pixel.x)+0.5)/width)-1`, `ny=1-(2*(float(pixel.y)+0.5)/height)`, `normalize(forward+right*nx*tanx+up*ny*tany)`, `position=cam+direction*primaryHit.t`. Composite currently ignores invalid/NaN/Inf primary hits. Mirror that.
- `producer.comp.glsl` derives producer key from **surface position**, while composite derives consumer key from **visible ray intersection point**; these may or may not coincide at quantization boundaries. Never label producer multiplicity as exact pixel consumer count.
- P1m0 test image must stay byte identical. No accepted shader modifications; N006-only opt-in diagnostic shader and isolated runtime buffers. Explicitly disallow requiring ray queries or changing composite G-buffer shader just to count coverage.
- Do not leak P1a-selected tiles into a future ranking threshold or holdout selection. The two P1b sites may only be **diagnostic control cases**.
- No GitHub Actions, no PR, preserve all B1a/B1c REJECT evidence; Issue #42 remains open until independent P1/P2 GO/STOP evaluation.

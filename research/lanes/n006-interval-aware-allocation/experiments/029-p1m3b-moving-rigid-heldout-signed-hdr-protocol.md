## Independent HDR quality reference, repeats and label

- In the **first baseline-only Q8 control frame**, call already accepted N001 CPU **8-diffuse-bounce** `n001_render_reference` with its verified convergence from GPU scene/readback state, using 512–8192 spp and existing absolute/relative replica threshold contracts. - Compute paired signed quality labels, in LINEAR FLOAT32 full-image RGB units and SAME Q8 representation, `gain_A = RMS(Q8_control,R_A) - RMS(Q8_candidate,R_A)` and `gain_B` analogously; gain below zero = quality worse, zero = neutral. Also report baseline/candidate RMS, full-image RGB modified pixels, region-free max and p99 RGB changes. Report independent reference RMS discrepancy `RMS(R_A,R_B)` as conservative metric-matched uncertainty bound (not the old p99 luminance reference noise), and `abs(gain_A-gain_B)` as signed estimate sensitivity. No arbitrary crops/cascade gains.
- An exploratory quality *signal* is recorded only if **both** independently referenced gains are positive AND each **exceeds** `RMS(R_A,R_B)`. This is intentionally conservative because the observed calibration effects are only 0.6–6.4e-6 and reference convergence noise may dwarf them. A weak positive sign below uncertainty is explicitly `not-detectable`, not proof of advantage. No implicit confidence interval claim from two references. Threshold is fixed before results. No cost/ROI/P2 release even if quality signal exists.
- Bounded stop for this heldout 1-scenario study: if 0/4 maximum-consumer key arms yield **repeated nonzero image influence**, stop Q8 +4 single-key image mechanism under moving-rigid; if nonzero pixels exist but no key passes conservative referenced quality signal, **STOP P1 predictive/ROI expansion** and record evidence as below-detection or negative. No P2 scheduler or HWRT-free superiority based on this pilot.

- N001 `light-motion` counterexample: CPU positive **9,546** / GPU positive 10,039; clear confirmation that the CPU tracer is **capable of producing nonzero reference images** in other frozen states.

From current GitHub source: CPU `n001_reference.cpp` uses fixed pixel-center primary rays and shadows each hit-to-point-light; N006 software compositor `n003_composite_software.comp.glsl` shadows **primary direct** but separately adds `lookup_probe` **indirect**; probe-hit radiance shader `n001_physical_radiance.comp.glsl` does not shadow-test the probe hit to the light. An unoccluded probe term is a **plausible** source of GPU-only signal, but the archived PFM images do not separate direct from indirect energy. Equally, reference scene-state mismatch or physically shadowed scene can lead to black CPU reference. **No root cause is proven**.

# スパイクの記録

1 スパイク 1 ファイル、1 ページ。ファイル名は `s1-screen-cascades.md` のようにする。

```markdown
# S? — 題名

- 期間：
- 問い：（ロードマップの仮説のどれを確かめたか）
- 打ち切り基準：（始める前に書く）

## やったこと
## 結果
（数値は「探索値」。計測条件、試した設定の範囲、画像を見て確認したことを書く）
## 判断
（続ける / 設計を変える / 捨てる、とその理由）
## 次
```

数値の要約（JSON か Markdown、1 MB 以下）はコミットする。生の出力は `out/` に置き、
要約を作ったら消す。

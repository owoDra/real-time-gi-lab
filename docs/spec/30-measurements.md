# 測った結果

**すべて探索値**（事前登録なし、各 1〜3 回）。条件は断りがなければ 1920×1080、AMD Radeon 8060S、Dawn / Vulkan
（RADV）、ネイティブ、ウォームアップ 60 ＋ 240 フレーム。GPU 時間は実行ごとに 20% 程度ずれる。開発機 1 台の結果で、
一般化しない。

- 数値の要約（JSON）：[reference/measurements/](../reference/measurements/)。
- 測ったときの記録の全文は、コミット `656e3ed2` の `research/spikes/*.md` にある
  （`git show 656e3ed2:research/spikes/m1-integration.md`）。そこに書いてある原因の推測と方針は、
  [40-dynamic-stability.md](40-dynamic-stability.md) と [50-roadmap.md](50-roadmap.md) が置き換えた。
- ここには測った事実だけを書く。解釈は 20 と 40 に置く。

## 1. 土台（2026-11-13）

- Sponza（26.2 万三角形）の G-buffer 1080p：中央値 0.63 ms（3 回、ウォームアップ 120 ＋ 600 フレーム）。
  60 フレームだけの試走では 1.03 ms（クロックの立ち上がり。ウォームアップは省けない）。
- 確保した GPU メモリ：シーン 415 MB（ほぼテクスチャ）、G-buffer 33 MB。
- **ブラウザでの GPU 時間は未計測。** この作業機ではブラウザの WebGPU が SwiftShader（CPU）に落ちる。ブラウザ版の
  コードが SwiftShader で動き、画像がネイティブとほぼ一致する（平均差 0.5/255）ことだけ確かめ、実行器は削除した
  （戻すときはコミット `876e2321` の `src/web/`、`tools/serve.ts`、`web/`）。

## 6. 局所更新（動的三角形を二値のブリックへ毎フレーム入れ直す方式。P2 で外した）

## 34. ブラウザで画像と時間を確かめた（2026-11-15、Phase 30）

要約：[reference/measurements/finish/phase30-browser.json](../reference/measurements/finish/phase30-browser.json)。探索値。1080p、既定の構成 `world-48-voxel-rc2-vrel`。
確かめたのは開発機 1 台（AMD Radeon 8060S、RADV STRIX_HALO の APU）と 1 つのブラウザ（Brave 1.91.168、Chromium 149）だけで、ほかの GPU、ドライバ、ブラウザには一般化しない。

- **結論**：ブラウザの WebGPU は実 GPU で動き（アダプタ `amd / rdna-3 / AMD Radeon 8060S Graphics (RADV STRIX_HALO)`、ソフトウェア描画でない）、**画像はネイティブとビット単位で同じ**、

- **起動の条件**（作業機）：Brave 149 の Linux では WebGPU が既定で切れている（引数なしではアダプタが無い）。`--enable-unsafe-webgpu --ignore-gpu-blocklist` で
  アダプタが出るが、Vulkan のローダーが見えないと SwiftShader に落ちる。`scripts/run_with_vulkan.sh` で起動し、Wayland の窓（`--ozone-platform=wayland`）にすると実 GPU になる
  （ヘッドレス、X11 の窓では SwiftShader か GPU プロセスの失敗）。GPU のサンドボックスは切っていない。同じ GPU とドライバの上の Dawn なので、ビット一致は
  この組み合わせに限った事実（別のドライバでは一致の判定（8 ビットで平均 0.5 段以下）で見る）。
- **画像の一致**（判定：同じ場面・同じフレームの間接光の 8 ビットの平均の差 0.5 段以下）：すべて差 0 段（間接光、最終、直接光の PNG と float の放射照度の sha256 が同じ）。
  `sponza`（空あり、静止、60 フレーム）、建物が波打ち物体 64 個（`sponza-dynobj-n64-deform-bwave --pose-frame 100`）、`sponza-toon`、建物が波打ち物体 64 個の通しの実行

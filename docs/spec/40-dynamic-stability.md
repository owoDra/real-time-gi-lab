# 動的なシーンでの跳び — 見立て、切り分け、対策

切り分け（E1〜E7）は 2026-11-14 に終えた。測った事実は [30-measurements.md](30-measurements.md) の 7 節、9 節
（E1・E5・E6）、10 節（E2・E3・E4 と方向ビンのレイ 4 倍）、11 節（E7）。**「見立て」のうち未検証と書いた部分と「対策」は、
まだ確かめていない。** 作業は [plan/dynamic-stability/](../plan/dynamic-stability/README.md) で進める。

## 方向（2026-11-14、ユーザー決定）

RC を土台に続け、遅れ 0 の前置フィルタで跳びを抑える。順番は E7（A の直接確認）→ 方向の確認 → P2 → P1。
P1 と P2 は DDGI 側にも入れ、同じ ms で比べ直す。E7 は済み（結果は「一部」、下の表）。P2 へ進むか、順番や中身を
変えるかは次の方向の確認で決める。

## 現象（測った）

- RC（履歴なし）は静止したシーンではちらつき 0。物体や太陽が動くと、床や壁の広い範囲が 1 フレームでまとめて跳ぶ。
  静止カメラのちらつきは 19.6%（太陽だけ 7.7%、物体だけ 17.9%）。DDGI は 1.3〜4.8%。
- プローブの押し出しを止めても変わらない（18.7 対 17.9%）。プローブを密にしても変わらない（P32 19.7、P48 19.6%）。
- 光源切替への応答は RC が 1 フレーム、DDGI は 11〜161 フレーム。
- 19.6% は、毎フレームの平均変化が約 0.05 段（3〜4%）であることに相当する
  （[10-evaluation.md](10-evaluation.md)「動的シーンのちらつきの読み方」）。
- **跳びの大半は往復で、本物の変化ではない。** 超過変動（K = 16、静止カメラ）は RC 0.081 段 / フレーム、DDGI 線形
  0.0021、RTXGI 既定 0.0006。RC の総変動の 67%（物体だけで 74%、太陽だけで 38%）が往復の分。線形の相対値でも
  RC は DDGI の約 40 倍で、暗い面だけの差ではない。DDGI の値は静的なシーンでの自分のノイズ（0.0011〜0.0018）と
  同じ程度。
- 超過変動の分布図では、物体から 5 m 以上離れた手前の床と左右の壁が一面に飽和している（物体だけを動かしても同じ）。
- 写実の物体で、物体だけの超過変動（0.065）は太陽だけ（0.013）の 5 倍。両方動かしたとき（0.062）は物体の分が占める。

## 見立て（2026-11-14、切り分けの結果で書き直した）

場は「格子点とワールドの状態」の決定的な関数である。静止時に 0 で、動くと跳ぶのは、その関数が不連続だからである。

測った事実（写実の物体、静止カメラ、K = 16 の超過変動）：

- **物体が動くときの跳びは、物体がトレースの世界（占有）に入っていることから来る。** 物体を占有から外すと 98% 消え、
  動く物体の影が静的なヒット点を横切る分（2%）だけが残る。物体に当たったヒット点の太陽の可視性は原因ではない
  （そこだけ 1 にすると、物体が明るくなる分だけ跳びは 11% 増える）。
- そのうち約 45% はボクセル固有で、占有の二値の切り替わり（B）による。細かい 2 つの層（0.1 m と 0.2 m）だけで 93% を
  占める。代表三角形の規則（C）は 1%。
- 残る約 54% は三角形トレーサでも残る。球だけを動かして解析的に分けると（E7）、その中身は 1 つではない。
  **角度の点サンプリング（A）は一部**：球を方向ビンの幅の錐で平均すると、レイ 1 本の解析的な球に比べて残りが
  48%（線形の絶対値で 45%）になる。残りの最大の分は、**物体の表面の 1 点で陰影を取ること**（以下 G）：レイが当たる
  点の法線と太陽の可視性が物体の上を滑る分で、球の放射を表面全体の平均にすると、三角形で残る球の分の 46%
  （log2）が消える。ただし線形の絶対値では 1% で、暗い所の log2 の変化が主である。錐にした後もまだ 20%（線形の
  絶対値で 45%）が残る。
- **太陽が動くときの跳びは、ヒット点の太陽の可視性を 1 点で取っていること（D）でほぼ説明できる**（その可視性を 1 に
  すると、超過変動が log2 で 91%、線形の絶対値で 93% 減る）。
- **サンプルを増やしても効きにくい。** 方向ビンあたりのレイを 4 倍（2×2 のサブレイの平均）にしても、超過変動は log2 で
  ボクセル −29%、三角形 +4%、線形の絶対値で −30〜40%。1/√4（−50%）にも届かない。

未検証の説明：E7 で錐にした後に残る分は、上のカスケードのプローブの位置の点サンプリング（位置の間隔は錐の断面より
粗いことがある）、ボクセルによるプローブの押し出しと遮蔽判定（球を含んだまま）、区間の奥行きの扱いのどれかと見ているが、
分けていない。また、物体の 1 点の陰影（G）のまま錐を広げると跳びは増える（log2 で 2 倍）。前置フィルタは遮蔽と放射の
両方をビンの断面で平均しないと効かない。

未検証の説明：物体がビンの中の別々のサブレイを順に横切ると、跳びは小さく数が増えるだけで、往復の合計は変わらない。
減るのは、物体が同時に複数のサブレイを覆うときだけである。上のカスケードの 1 サンプルは配下の広い領域で共有されるので、
跳びは面でそろう。要るのはサンプル数ではなく、ビンの断面に合った大きさで遮蔽と放射を平均すること（空間・角度の前置
フィルタ）である。時間方向の平均ではないので、遅れは出ない。DDGI も同じ 1 ビン 1 サンプルで、回転と時間平均によって
この不連続を遅れに換えている。

元の見立て（本命は角度と位置の点サンプリング）のうち、「位置」（ヒット点の 1 点）は、太陽が動く場合は太陽の可視性
（D）として、物体が動く場合は物体の上の陰影（G）として当たった。「角度」（A）は一部だけ当たった。占有の二値（B）が
物体 3 つのとき約半分を占める。

## 原因ごとの寄与（2026-11-14、探索値）

写実の物体だけを動かす `sponza-dynobj-objectsonly`、既定の構成（ボクセル `rc2-vrel`、局所更新）、静止カメラ、各 1 回。
基準は超過変動 0.0650 段 / フレーム、帯境界ちらつき率 17.07%。割合は基準に対する値。1 つの画素は原因がいくつあっても
1 回しか数えないので、行は足し算にならない。

| 原因 | その原因だけを外したときに減る分（超過変動 / ちらつき） | その原因だけを残したときに出る分（超過変動 / ちらつき） | 実験 |
|---|---|---|---|
| B 占有の二値（ボクセル固有から C を除いた分） | 約 45% / 約 27% | — | E1 − E3 |
| C 代表三角形の規則 | 1.2% / 1.1% | — | E3 |
| D 動く物体の影が静的なヒット点を横切る | — | 2.1% / 7.6% | E2（層なし） |
| D 物体に当たったヒット点の可視性 | −11% / −35%（外すと増える） | — | E4（物体だけ 1） |
| F プローブ集合 | 0 / 0 | — | E6 |
| 三角形でも残る分（A、G、残り。D の 2% を含む） | — | 54% / 72% | E1 |
| 層ごと（物体を入れる層） | — | 層 0：29% / 39%、層 0〜1：93% / 90%、層 0〜2：99% / 98%、層 0〜3：100% / 100% | E2 |

- 重なり：外したときの B と C（46%）と、三角形で残る分（54%）は、同じ 1 組の比較から出しているので合わせて 100% になる。
  D の 2% は三角形で残る分の中に含まれる。
- **三角形で残る分の中身（E7、球だけ、`sponza-dynobj-sphereonly`）。** 基準は三角形で残る球の分（三角形 0.0228 −
  球を GI のレイから外した 0.0020 = 0.0208）。差の連鎖なので足すと 100% になる。

  | 分 | 超過変動（log2、K = 16） | 線形の絶対値 |
  |---|---|---|
  | 解析化そのもの（三角形の球 → 解析的な球、1 点の陰影、レイ 1 本） | 12% | 19% |
  | G 物体の表面の 1 点の陰影（→ 表面全体の平均の放射） | 46% | 1% |
  | A 角度の点サンプリング（レイ 1 本 → 方向ビンの幅の錐） | 22% | 35% |
  | 錐にした後に残る分（説明できていない） | 20% | 45% |

- 球だけのシーンで、ボクセル（0.0303）と三角形（0.0228）の差は 25%。物体 3 つの 46% との違いは、リングと人形
  （細い形と複雑な形）で占有の二値（B）が大きいためと見ている（未検証）。
- **説明できていない残り**：三角形で残る球の分の 20%（線形の絶対値で 45%）。上のカスケードのプローブの位置、
  ボクセルの押し出しと遮蔽判定、区間の奥行きの扱いを候補と見ているが分けていない。ちらつき率は本物の変化も含む。
- トゥーンの物体を基準にした場合は、E（トゥーンの放出の量子化）が 0.081 の約 2 割を占め、残りが上の内訳になる。
- 太陽だけを動かす `sponza-dynobj-sunonly`（基準 0.0130、8.12%）では、D を外すと超過変動が 91%（線形の絶対値で 93%）
  減り、ちらつきは 4.33% になる（残りは本物の変化と、場が明るくなった分）。そのうち物体に当たったヒット点の分は、
  線形の絶対値で約 2 割。

## 対策（未検証）

| 案 | 内容 | 狙う分 | 費用の見積もり（未計測） | 目安 | 外れの見分け方 |
|---|---|---|---|---|---|
| **P1 ヒット放射の前置フィルタ** | 毎フレーム、層 0 の占有ボクセルに直接光を注入し（表裏 2 値）、上の層へ平均する。ヒット時は錐の幅に合う層から読む。形状と放射の更新を分ける | 太陽が動く分（D）。物体が動く分のうち G（物体の上の 1 点の陰影）にも効く見込み（未検証。E7 では放射を表面の平均にすると log2 で 46% 消えたが、線形の絶対値では 1%） | 注入と平均で +0.1〜0.2 ms。トレース中の影の参照が消えるので相殺の見込み。+6 MB 程度 | `sunonly` の超過変動 0.013 → 0.003 以下（E4 の上限は 0.0012） | 下がらない。リーク部屋が悪化する（表裏の分離が効いていない） |
| **P2 動的物体だけ被覆率レイヤ** | 静的な形状は今の二値のまま（動かないので固定の偏りにしかならず、リーク耐性を保つ）。動的三角形は軸別の被覆率と平均放射を固定小数の加算で書き、透過率を積む。まず層 0〜1 に限る（跳びの 93%）。代表三角形の扱いは要らない（C は 1%） | 物体が動く分の B（約 45%）。A まで抑えるには、被覆率をビンの錐の幅で読む必要がある（E7 で A は一部、三角形で残る球の分の 22%、線形の絶対値で 35%） | 動的ブリックを通るレイだけ追加で +0.1〜0.3 ms。メモリは誤差程度 | `objectsonly` の超過変動 0.065 → 0.035 以下（三角形と同じ）で B が取れたとみる。DDGI 線形の 2 倍（0.0044）に届くには A も要る | 下がらない。動く遮蔽物でリークが増える |

- **E7（済み、2026-11-14）**：動く球を解析的な「錐と球の被覆」に差し替えた。A は一部（目安で 30〜70%）。錐の幅で
  平均するのは、放射も同じ幅で平均したとき（表面の平均）にだけ効き、1 点の陰影のまま錐を広げると跳びは増える。
  解析プロキシはトポロジの変化に対応できないので本採用しない（スイッチは消した）。
- P1 と P2 は構成上遅れが出ない。動かした値と止めた値のビット一致、応答 1 フレームがそのまま検証になる。
- P2 はボクセルコーントレーシングと同じ弱点（部分透過の積による遮蔽の過小）を持つ。動的レイヤに限るのはそのため。
- どの対策も GI 4 ms と 128 MB の中で入れる。既定の構成は 3.4〜3.5 ms で、余りは約 0.5 ms。
- カメラ移動時のちらつき（静的なシーンで 15.8%）は LOD と登録の変化が候補の別問題で、P1・P2 では下がらない。

**P1 と P2 は DDGI のレイにも同じだけ効く**（被積分関数が滑らかになれば、低いヒステリシスでもちらつかない）。
RC にだけ入れて比べない。

## やらないこと

- サンプルを増やして抑える（方向数、タップ数、プローブ密度）。方向ビンのレイ 4 倍で 0〜40% しか減らなかった。
- 占有の被覆率化だけを単独で入れる（錐の幅で読まなければ A は残る）。
- 代表三角形の規則を変える（C は 1%）。
- 履歴を RC に足す。長い履歴（ヒステリシス 0.9 以上の指数平均）は R1 を失い、DDGI と同じ三すくみに入る。
- 予算（4 ms、128 MB）を緩める。

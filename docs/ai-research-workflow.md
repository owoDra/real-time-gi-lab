# AI による研究と人間の監督

このリポジトリは、AI を使った半自律的な作業で進めたリアルタイム GI 研究の記録である。
人間だけが書いたコードでも、無人で動く自律研究システムでも、AI が発見した成果の証明でも
ない。

## 誰が何をしたか

| 役割 | 担い手 |
|---|---|
| 研究の方向、優先順位、制約、中止や転換の判断 | 人間 |
| 文献調査、仮説、実験計画 | AI が提案し、人間が判断 |
| コード、シェーダ、テスト、スクリプト、文書 | 主に AI が作成 |
| GPU 実験の実行 | Program 1 の前半は人間が操作。後半は明示的な許可のもとで AI が作業機で実行 |
| 結果の採否 | 記録された計測に基づき、人間が監督 |

使ったツール：

- Program 1（2026-09-28〜2026-11-13）：ChatGPT と OpenAI Codex CLI。N008（2026-10-13）
  以降は Claude Code（Anthropic）も使用。
- Program 2（2026-11-13〜）：Claude Code。

ツール名は透明性のために記すもので、提供元による推奨や認証ではない。

## 読むときの注意

- 根拠は計測結果である。AI の説明は計測を上書きしない。
- Program 1 の計測の大半は AMD Radeon 8060S（RADV STRIX_HALO）1 台と限られたシーンで
  行った。他の GPU、シーン、手法に外挿しない。
- Program 1 の終了と Program 2 の方針は、AI による全記録の評価を踏まえて人間が決めた。
  その評価で、Program 1 の開発データの一部が意図どおりでなかったことが見つかっている
  （[記録](program-1/dev-sequence-validity-check.md)）。AI が進めた研究には、この種の
  見落としがあり得る。
- Program 1 の生データ（約 411 GB）は作業機から削除した。コミット済みの記録に残る
  ハッシュは、もう実データと照合できない。再現するには記録された SHA のソースを
  実行し直す必要がある。
- Git のコミット著者は、人間と AI のどちらが書いたかを行単位で示すものではない。

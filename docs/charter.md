# 研究憲章 — Program 2

2026-11-13 開始。Program 1（M0、Lane A〜N、N005〜N010、Lane M）の記録はタグ
`archive/program-1` にあり、要点は [program-1/findings.md](program-1/findings.md) にまとめてある。

## 目的

次の3つを同時に満たすリアルタイム・グローバルイルミネーション（GI）を作る。

1. **完全動的なワールドで、高速・軽量・高品質に動く。** ジオメトリ、光源、カメラ、
   トポロジのすべてが毎フレーム変わってよい。事前計算やベイクに依存しない。
2. **フォトリアルとノンフォトリアルを同じ空間で混在させられる。** トゥーンのキャラが
   写実的な部屋に立ち、互いに照り返しを与え合える。
3. **WebGPU で動く。** WebGL2 は機能を絞った縮退ティアとして、可能なら対応する。

## 必須要件

| ID | 要件 |
|---|---|
| R1 | 完全動的：履歴なしでも破綻しない。光源切替への応答は数フレーム以内 |
| R2 | 大規模ワールド：GI の時間とメモリがワールドの広さにほぼ依存しない |
| R3 | 高密度ワールド：GI の時間が三角形数ではなく表面積と解像度で決まる |
| R4 | 無ノイズ・時間安定：閾値処理（トゥーンのランプ）を通してもちらつかない |
| R5 | スタイル混在：スタイルの異なる物体が同じ放射輝度場を共有する |
| R6 | WebGPU のコア機能だけで動く：ハードウェアレイトレーシングを前提にしない |

望ましいもの（必須ではない）：WebGL2 ティア、既存手法を越える新規の発想。

## 「高品質」の定義

パストレーシングと同等、という意味ではない。次を指す。

- 時間的に安定している（静止時にちらつかず、動かしても尾を引かない）。
- 光が壁を抜けない。
- 写実的な部分の誤差が測定されていて、同じコストの既存手法より小さい。

Program 1 の「間接 NRMSE ≤ 10%、全画素」というゲートは使わない。あのゲートを通るのは
収束に近いパストレーシングだけで、リアルタイム GI の良し悪しを測れなかった。

## 対象外（v1）

- パストレーシング同等の画質。
- 鏡面に近い光沢反射。拡散と粗いスペキュラまでを扱う。
- ニューラル手法、シーンごとの学習。
- 複数デバイスでの検証を完了条件にすること。開発機（AMD Radeon 8060S）での結果は
  その機種の結果として述べ、一般化しない。ブラウザやデバイスの移植性確認は後段の
  マイルストーンで行う。

## 成功条件

評価は「同じ品質での速さ」ではなく「**同じコストでの品質**」で行う。予算、指標、
比較相手、シーンは [evaluation.md](evaluation.md) に定める。

成功とは、固定予算の中で R1〜R6 を満たし、Web で実現可能な既存手法（SSGI、DDGI 系、
ボクセルコーントレーシング）に対して品質または対応範囲で優位を示すこと。

## 止め方

Program 1 には停止規則がなく、使い捨ての評価データを消費しながら候補を作り直す
ループになった。Program 2 では次を守る。

- 各スパイクは打ち切り基準を先に書く（[roadmap](../research/roadmap.md)）。
- スパイク S1〜S3 の後に必ずチェックポイントを置き、**継続・方向転換・中止**の
  いずれかを決める。中止は正当な結果である。
- 方針の変更は [research/decisions/](../research/decisions/) に1件1ファイルで残す。

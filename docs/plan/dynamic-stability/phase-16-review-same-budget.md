# Phase 16（review）：同じ 4 ms で DDGI 系に優位があるか

## 開始プロンプト

```
AGENTS.md と docs/plan/README.md と docs/plan/dynamic-stability/README.md と docs/plan/dynamic-stability/phase-16-review-same-budget.md を読み、Phase 16（review、方向の確認）を進めてください。Phase 15 の測った結果（spec/30-measurements.md の 19 節と docs/reference/measurements/dynamic-stability/phase15-widen-measure.json）を材料に、同じ GI 4 ms・128 MB で RC（既定と p1）が DDGI 系（0.75 m 線形と RTXGI 既定）に対して優位を持つかを AI が判断し、次の列（大規模・高密度）へ進むか、P1 を既定に入れるか（読む層を細かくして太陽の分を一部手放す形を含む）、動的物体が多いときの動的レイヤの費用、多重バウンスの扱いを決めてください。比べる画像（同じ画角・同じフレーム、超過変動の分布図、参照との並び）は描き直してそろえ、決めた案、理由、画像と数値を 1 枚の非公開の Artifact にし、ユーザーに平易に報告してください。ユーザーに技術の選択を求めないでください。目標か予算に関わる判断は AskUserQuestion で尋ねてください。
```

## 目的

Phase 15 の条件を広げた計測で、RC と DDGI 系の比べの結論が条件で変わったかを読み、方向を決める（継続・方向転換・中止はこの種類でだけ決める）。

## 前提（Phase 15 で測った。詳細は spec 30 の 19 節）

- 静止カメラの超過変動では RC は DDGI 線形の 13 倍（既定）/ 4 倍（`p1`）だが、移動カメラの超過変動では差が縮む
  （`sponza-dynobj`：log2 で既定 1.75 倍・`p1` 1.50 倍、線形で 1.33 倍・1.11 倍）。移動カメラの値の大半は測定の床
  （静的な `sponza` で DDGI 0.042）で、静的な `sponza` では RC の方が大きい（既定 0.066、`p1` 0.086。視点で場が変わる分）。
- 動的物体を 12 / 24 個に増やすと、動的ブリックが 368 / 535 個要り、上限 256 ではあふれて RC の超過変動が跳ぶ（0.027 / 0.060）。
  上限 1024 なら 3 物体と同じ程度（0.011〜0.012、`p1` 0.004）。動的レイヤの作成が物体の数にほぼ比例し、24 物体で GI が 4 ms を超える
  （RC も DDGI も同じレイヤを読むので両方）。
- メモリ：作成用の一時バッファを解放し、ボクセルのプールを Sponza に合わせて絞った既定で、作っている途中を含めて全設定が 128 MB 以内
  （予算は作っている途中にも当てはめる：ユーザー 2026-11-14）。WebGPU の既定の上限で全設定が動き、画像はビット単位で同じ。
- **目標（ユーザー 2026-11-14）：動く物体は数十個、剛体だけでなく変形するメッシュも。** 今の動的レイヤは費用が動的三角形の数に比例し、
  24 物体で 4 ms を超える。この目標に向けて動的物体の扱いの作りを変えるかを、ここで決める。
- 参照との誤差は Phase 13 までと同じ（静的な `sponza`：RC 0.400、`p1` 0.380、DDGI 0.362 / 0.384）。
- GPU 時間は spec 30 の 19 節（3 回、GPU はブラウザ、エディタと共有）。

## 決定済みの方針

- 予算（GI 4 ms、128 MB）と指標は変えない。技術の選択はユーザーに求めない。
- 比べは同じ場面、同じ解像度、同じ予算で、一方にだけ入れた改良で比べない（DDGI の `-p1` を対に置く）。

## 確かめる決定と、その確かめ方

| 決定 | 確かめ方 |
|---|---|
| 優位の判断 | 静止・移動カメラの超過変動、参照との誤差、応答、リーク、GI、メモリを、既定・`p1`・DDGI 2 種で並べた表と画像で判断し、理由を書く |
| 次の列へ進むか | 判断の結果で、`docs/plan/README.md` の列の表と spec 50 を書き直す |
| P1 | 既定に入れるか、読む層を細かくする形を試すフェーズを置くか |
| 物体が多いとき | 数十個の動く物体と変形するメッシュ（ユーザーの目標）に向けて、動的レイヤの作成の費用（物体の数に比例）をどうするか |
| 多重バウンス | 扱いを決めて spec に書く |

## 目的

跳びのうち、どの原因が何割を占めるかを数で出す。Phase 03 でユーザーが方向を決める材料にする。

## 前提

Phase 01（指標、再現、E6・E5・E1 の結果）。

## 決定済みの方針

- 候補と実験の定義は `docs/spec/40-dynamic-stability.md`。
- 層ごとの寄与は、更新を遅らせるのではなくマスクで測る。
- 寄与は足し算にならない（1 つの画素は原因がいくつあっても 1 回しか数えない）。「その原因だけを外したときに減る分」と
  「その原因だけを残したときに出る分」の両方を出し、合わない分を「重なり」として書く。
- Phase 01 の結果（2026-11-14、探索値、静止カメラ。数値は `spec/30-measurements.md` 9 節）：
  - 7 節の値は再現した（19.55 / 7.67 / 17.88%）。
  - 超過変動は `src/core/post.ts` にある（log2、K = 8 / 16 / 32、線形の相対値を K = 16 で併記、動的物体か無効だった
    画素の窓は数えない）。`staticFinePct` は動的物体でない画素だけの帯境界ちらつき率。超過変動は静止カメラでだけ出る。
    判定は K = 16 の log2 の値で行い、線形でも同じ向きかを添える。
  - RC の超過変動は 0.081 段 / フレーム（両方、物体だけ）、0.013（太陽だけ）。DDGI 線形 0.0021〜0.0024、RTXGI 既定
    0.0004〜0.0012（静的なシーンでの DDGI 自身のノイズ 0.0011〜0.0018 と同じ程度）。
  - F（プローブ集合とあふれ）は棄却。E は一部（写実材質で 0.081 → 0.065、約 2 割。太陽だけでは変わらない）。
    B・C は合わせて支持（写実の物体で、ボクセル → 三角形で 0.065 → 0.035、約 46% 減）。A と D は未定：三角形でも
    写実の物体で 0.035 が残る。押し出し（`vrel` / `norel`）は寄与しない。
  - 三角形 BVH は動的なシーンで毎フレーム CPU で再フィットする（`refitBvh`、GPU 時間の外）。三角形トレーサで
    動的なシーンを測れる。
  - 寄与の基準は、写実の物体（`sponza-dynobj-*`）にしてトゥーンの放出の量子化（仕様どおりの変化）を除いた値にする。

## 確かめる決定

| 決定 | 確かめ方 |
|---|---|
| 既定の構成の画像を変えない | 診断用のスイッチを切った状態で、既定の構成の静的な放射照度がビット単位で同じ。フェーズの終わりにスイッチが消えている |
| 予算は変えない | 診断の実行の時間は判定に使わない。既定の構成の時間を 1 回読んで 30 の 7 節と比べる |
| 層の寄与はマスクで測る | E2 の実装が、層ごとに動的三角形を入れる / 入れないの切り替えである |
| 数値の前に画像を見る | 各スイッチの最後のフレームとちらつきの分布図を見る。E4 は画像が正しくない（影のない照り返し）ことを確かめたうえで、ちらつきだけ読む |
| 切り分けが終わるまで対策を実装しない | 差分に P1・P2・P3 の実装が無い |

## やること

1. E4：ヒット側の太陽の可視性を常に 1 にするスイッチを足し、`sponza-dynobj-sunonly`（ボクセル）と
   `sponza-dynobj-objectsonly`（ボクセルと三角形 `tri-rc2-vrel`）で測る。三角形で残る 0.035 のうち、D（動く物体の影が
   ヒット点を横切る）の分を外し、残りを A とする。
2. E2：動的三角形を入れる層をマスクで掃引する（なし / 層 0 / 層 0〜1 / 層 0〜2 / 層 0〜3 / 全部）。
   `sponza-dynobj-objectsonly`。
3. E3：全再構築で、重なったときに静的三角形が勝つ規則にして測る（局所更新のビット一致は動的三角形が末尾にある
   ことに依るので、この実験は全再構築で行う）。
4. 見立ての確認を 1 回だけ：方向ビンあたりのレイを 4 倍にした場合（計測外、時間は見ない）のちらつきが、
   約半分（1/√4）になるか。ならなければ、見立てと「サンプルを増やしても効きにくい」を書き直す。
5. 寄与の表を作り、spec へ還元する。Phase 03 のファイルを結果に合わせて書き直す。

## 完了条件

- E4、E2、E3 の結果が spec 40 の表に入り、候補 A〜F すべてに支持・棄却・未定が付いている。
- 原因ごとの寄与の表が spec 40 にある。
- spec 40 の見立てと対策の案が、測った結果と食い違っていない。

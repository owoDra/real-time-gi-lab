# Phase 11（review）：P1 を 4 ms に入れる道があるか、P1 なしで進むかを決める

## 開始プロンプト

```
AGENTS.md と docs/plan/README.md と docs/plan/dynamic-stability/README.md と docs/plan/dynamic-stability/phase-11-review-p1-cost.md を読み、Phase 11（review）を始めてください。直した P1（設定のトークン p1）はリークと暗さを満たしたが GI が 4 ms を超えた。このファイルの「見直す問い」の 1〜4 に答え、P1 を 4 ms に入れる道を作って試すか、P1 なしで条件を広げる計測へ進むかを、理由をつけて決めてください。主な主張はソースか計測（計測だけ、GPU ジョブは同時に 1 本）で確かめ、助言と決定を 1 枚の非公開の Artifact にまとめ、ユーザーに平易に報告してください。技術の判断は自分で決めて報告してください。決めた方向を spec に日付つきで書き、後のフェーズのファイルを書き直してください。
```

## 目的

P1（ヒット放射の前置フィルタ）は、太陽が動く跳びを 76% 減らし、Phase 10 でリークと暗さも直した。しかし GI は静止
4.27〜4.38 ms、移動 4.20〜4.39 ms で、予算の 4 ms に入らない（既定の構成より 0.35〜0.45 ms 重い）。P1 は既定に入れていない。
このフェーズで、次に何をするかを決める。物はまだ作らない（確かめるための計測はしてよい）。

## 前提

- 結果：[spec/30-measurements.md](../../spec/30-measurements.md) の 14、15 節、要約
  [phase10-p1-fixed.json](../../reference/measurements/dynamic-stability/phase10-p1-fixed.json)。作りは
  [spec/20-renderer.md](../../spec/20-renderer.md) の「P1」、見立ては [spec/40-dynamic-stability.md](../../spec/40-dynamic-stability.md)。
- Phase 10 の確認ページ（非公開）：https://claude.ai/artifact/EmeHtnWw39ET5c9BaM2YKv（ユーザーは見て OK）。
- Phase 10 の計測は GPU を別のプロセスと共有していた時間を含み、既定の GI も 3.83〜4.00 ms と Phase 09（3.46〜3.71 ms）より
  遅かった。差（+0.35〜0.45 ms）で判断した。
- 上乗せの内訳：ボクセルの段 0.28 → 0.62 ms（注入 約 0.21、うち 16 点の読み 約 0.15。平均 約 0.07）、トレース +0.03〜0.05 ms。

## 見直す問い

1. **P1 を 4 ms に入れる道はあるか**：P1 以外の段（`vrel` の判定 約 0.75 ms、ボクセル化、トレース）を軽くして余りを作る、
   注入を別の形にする（シャドウマップでなくボクセルの太陽の可視性を使う、など）。予算、履歴なし、サンプルを増やさない、
   という決まりの中で、見込みを数字で書く。
2. **P1 なしで進めてよいか**：P2 だけの既定の構成で、DDGI 線形との跳びの差は 2.5 倍（物体だけ）〜13 倍（物体と太陽）。
   この差のまま、条件を広げる計測と同じ 4 ms での比べへ進んで、判断が成り立つか。
3. **カメラが動くときのちらつき**：直した P1 で 15.8 → 19.6% に増えた。原因の見立て（読む層がカメラからの距離で切り替わる）
   を確かめるか、P1 を入れるときの条件にするか。
4. **順番**：この列の残り（条件を広げる計測、同じ 4 ms での比べの review）の前に、何を置くか。

## 決定済みの方針

- 予算（GI 4 ms、128 MB）と判定の目安は変えない。履歴を足さない。サンプルを増やす方向は試さない。
- 技術の選択はユーザーに求めない。AI が理由をつけて決め、平易に報告する。
- 確かめるための計測は画像を変えない計測だけ。GPU ジョブは同時に 1 本。費用は前と後を交互に 3 回測り、GPU の共有の
  有無を書く。

## やること

1. 前提を読み、問いの 1〜4 に答える。必要なら計測だけで確かめる。
2. 助言と決定を 1 枚の非公開の Artifact にまとめ、ユーザーに平易に報告する。
3. 決めた方向を spec（40、50）に日付つきで書き、次のフェーズのファイルを作り、列の表を書き直し、このファイルを消す。

## 完了条件

- 次のフェーズのファイルがある。

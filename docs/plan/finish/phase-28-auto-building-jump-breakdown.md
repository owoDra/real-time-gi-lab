## 目的

段階 D の問いの前半。建物が動くと RC の場が跳ぶ（R4 を満たしていない）。どこで跳ぶのかを測ってから直す。

## 前提（[spec 30 の 29〜31 節](../../spec/30-measurements.md)）

- 跳び（超過変動 K = 16、静止カメラ、Phase 27 の直した床＝法線マップを外した値）：`sponza-dynobj-n64-deform-bwave` RC 0.114 対 DDGI 線形 0.038
  （法線マップあり 0.178 対 0.106。見かけの分は RC 0.064、DDGI 0.068 で、両方にほぼ同じだけ乗っていた）、`town-dynobj-bwave` 0.239 対 0.0074
  （法線マップが無いので同じ）、`sponza-dynobj-n64-deform-bcut` 0.0345 対 0.0010、`sponza-bcut`（物体なし）0.0028 対 0.0010。
  移動カメラ（鎖の超過変動、法線マップなし）：建物が波打つ Sponza で RC 0.089 対 0.0063、`town` で 0.178 対 0.0033。
  静止カメラのちらつきは `town` で建物が波打つと RC 23.4% 対 5.6%。
- 物体 64 個が動き建物の一部が現れて消える場面（0.0345）は、物体なしの同じ場面（0.0028）と物体 3 つで建物が止まった場面（0.0113）の和より大きい。
  物体の数と建物の変化が重なる分がある（未検証）。
- 黒い欠け：面が層 0 のボクセルの面に乗ると間接光が欠ける（`town-grid`、偏り −33%。DDGI も −28%）。建物が波打つ `town` の地面の黒いギザギザ、
  等倍で細い形の近くの小さな黒い欠け、物体 3 つの場面の球の右下の欠け。
- 建物は二値の占有。動くとボクセルが入れ替わる。物体は被覆率のレイヤ（P2）で跳びが 95% 減った。建物も同じレイヤにする形は、
  費用（splat に比例）とメモリ（38 MiB）で Phase 20 に採らなかった。
- 見立て（未検証）：跳びと黒い欠けは同じ原因（二値の占有の切り替わりが、プローブの押し出し、遮り判定、ヒットの 3 か所に出る）。

## 決定済みの方針

- 切り分けはマスク（その要素を完全に外すか、止めた形状の値に固定する）で行う。更新を遅らせる実験は使わない（[spec 10](../../spec/10-evaluation.md)）。
- 外す要素：(a) 法線マップは Phase 27 の直した床（法線マップを外した値を主に読む）で済んだので省く。(b) プローブの押し出し（置き場所を止めた形状のものに固定）、
  (c) gather と合成の遮り判定（同じく固定）、(d) レイのヒットの占有（トレースだけ止めた形状のボクセルを読む）、(e) ヒットの代表三角形の材質と法線、
  (f) 跳ね返りボリューム、(g) 三角形トレーサ（`tri`）に替えたときの残り（ボクセルに依らない分）。
- 黒い欠けは、`town-grid` と `town-dynobj-bwave` で、黒い画素（8 プローブとも遮られた画素）の数と場所を出し、(b)(c) のどちらで生じるかを分ける。
- Phase 29 で直す所は、寄与の大きい順に、予算の余裕（Phase 27 の再現値）に入るものを選ぶ。候補（未検証）：層 0 の占有に部分的な値を持たせる、
  押し出しと遮り判定を占有の切り替わりで跳ばない形にする、c0 の放射照度に R1 が許す数フレームの短い履歴を持つ（応答 4 フレーム以内）、
  面がボクセルの面に乗る場合の判定の向きを決める。
- DDGI 系でも同じ診断のうち共有のトレーサに関わるもの（d、e）を測る。

## 確かめる決定と、その確かめ方

| 決定 | 確かめ方 |
|---|---|
| 以前の数値を再現する | 上の 3 場面の跳びと `town-grid` の偏りを最初に再現する（Phase 27 の直した床の値で）。建物が波打ち物体 64 個の GI の時間の絶対値（3.67〜3.80 ms）も測り直す。Phase 27 の日は別のプロセスが GPU を使い続けていて 4.06〜4.22 ms だった（Phase 26 の実行器も交互に測って 4.24〜4.33 ms）。測る前に何も回していないときの GPU の使用率を見て、空いていなければ Phase 26 の実行器（`git show b841c61c` から作る）と交互に測って差で言う |
| 既定の画像を変えない | Phase 27 と同じ sha256 |
| 内訳が足りている | 外した要素の寄与の和が、跳び全体の 7 割以上を説明する。届かなければ残りを「説明できていない分」として書く |
| 画像を先に見る | 要素を外した連番と超過変動の分布図、黒い画素の分布図 |
| Phase 29 を書き直した | 直す所、作り方、費用の見込みが Phase 29 のファイルにあり、目安 S1〜S6 の判定が変わっていない |

## やること

1. 再現。2. 診断のスイッチを入れて測る。3. 画像を見る。4. 直す所を決め、Phase 29 のファイルを書き直す。
5. 診断のスイッチを消す。還元：spec 30、40、50、要約。

## 止める条件

内訳の最大の要素が、どの候補でも余裕に入る形で直せないと分かったとき。Phase 29 を review（方向の確認：建物の跳びを残したまま進むか、土台を変えるか）に差し替える。

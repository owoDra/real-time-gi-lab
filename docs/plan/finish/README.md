進め方、プロンプトの使い方、共通の完了定義は [`../README.md`](../README.md)。

完全動的の列（[`../full-dynamic/`](../full-dynamic/README.md)）の比べ直し（Phase 26）で「続ける」と決めた後に始める列。
**Phase 26 より前に書いた計画なので、Phase 26 の決定と、段階 A・B でできた構成に合わせて、始める前に書き直す**

## この列のきまり

- 画像を変える auto を 2 つ続けない。一方にだけ入れた改良で比べない。明るさの正しさは参照（Mitsuba）で言う。
- 予算は GI 4 ms、128 MB（作っている途中も含む）。変えない。予算に近い GPU 時間は 3 回測って範囲を書き、前後は交互に測る。
- 判定は「建物を含む全形状が同じフレームに変わる」場面で行う（2026-11-14、ユーザー）。
- サンプルを増やす方向（方向数、タップ数、プローブ密度）は試さない。
- 段階 G より前は、計測はネイティブ（Dawn / Vulkan）だけ。GPU ジョブは同時に 1 本。参照を描いている間は GPU 時間を測らない。

# Phase 35（built）：WebGL2 の縮退版を、ユーザーが実物で確かめる

Phase 34 が止める条件で終わった場合は、このフェーズを消す。

## 開始プロンプト

```
AGENTS.md と docs/plan/README.md と docs/plan/finish/README.md と docs/plan/finish/phase-35-built-webgl2.md を読み、Phase 35（built）を進めてください。Phase 34 で作った WebGL2 の縮退版と WebGPU の版を、同じ画角・同じフレームで並べた画像と連番、できる事とできない事の一覧、費用を 1 枚のページにまとめて非公開の Artifact に公開してください。私が気になる所を挙げたら直して測り直し、同じ URL へ再公開してください。最後に AskUserQuestion で、この縮退版を残すかどうかの OK を取ってください。報告は専門用語の表にせず平易に書いてください。
```

## 目的

段階 H の出口。縮退版の見た目が「機能を絞った版」として受け入れられるかを、ユーザーが決める。

## 決定済みの方針

- ページの先頭に、できない事の一覧（画面の外の光、遠くの遮りなど）と、その場面の画像を置く。
- 場面：`sponza`、トゥーンの物体、物体と光が動く場面、建物が変わる場面、移動カメラ。

## 確かめる決定と、その確かめ方

| 決定 | 確かめ方 |
|---|---|
| できない事を隠さない | ページの先頭の一覧と画像 |
| ユーザーの OK | AskUserQuestion（残す / まだ直してほしい（どこを）/ 残さない） |

## やること

1. ページを作って公開する（URL をここに書く）。2. 指摘を直して再公開する。3. 決定を spec 20 と 50 に書く
   （「残さない」ならコードを消す）。

## 完了条件

- ユーザーの決定がある。共通の完了定義（[`../README.md`](../README.md)）を満たしている。

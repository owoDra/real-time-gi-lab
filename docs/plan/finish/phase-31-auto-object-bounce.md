## 目的

段階 F。目的 2（トゥーンのキャラが写実の部屋に立ち、互いに照り返す）の主役は動く物体だが、今は多重バウンスの輪の外にいる。

## 前提（[spec 20](../../spec/20-renderer.md)）

- 動的レイヤの放射は直接光だけ（物体に当たったレイは、物体が受けている間接光を返さない）。跳ね返りボリュームの光線は動的物体を見ない
  （物体は跳ね返りの光を遮らない）。
- P2 の物体の近くの床は参照の 1.0〜1.9 倍明るく、球の真下の暗がりが出ない（原因は分かっていない）。
- 動く物体の画素の参照との誤差（8 × 8 ブロック）と偏り（Phase 27、[spec 30 の 31 節](../../spec/30-measurements.md)。参照は多重バウンス 128 spp 1 本、
  `box/out/mitsuba/sponza-dynobj-n64-deform-f0`・`-f100`。DDGI はウォームアップ 2400 フレームで姿勢を止めて収束させた値）：
  `sponza-dynobj-n64-deform` 姿勢 0（太陽が物体に当たる）RC 0.354 / −28%、DDGI 線形 0.526 / −45%。姿勢 100（物体は日陰）RC 0.276 / −17%、DDGI 線形 0.490 / −43%。
  物体 3 つ（`sponza-dynobj` 姿勢 0）RC 0.396 / −32%。参照には物体どうしの色の照り返しと、物体の下と間の床の暖色の照り返しがあり、RC と DDGI のどちらにも無い。
  比べ方：`--pose-frame N --static-only --dump-irr --frames 60`（DDGI は `--warmup 2400` を足す）の後、`ref:compare -- --objects`。
- トゥーンのランプの帯の切り替わり（静止カメラ）：RC 1.26〜2.19%、DDGI 線形 1.03〜1.05%、対照 1.15%（Phase 25）。

## 決定済みの方針

- 作り方は AI が決める。最初の候補（未検証）：動的レイヤの点の陰影に、その点の跳ね返りボリュームの放射照度 × アルベド / π を足す
  （1 フレーム遅れの読み）。跳ね返りボリュームの光線が動的レイヤの被覆率を読む。
- トゥーンの物体は、受けた間接光を放出側の演算子に通さない（演算子は太陽の項だけ。今の決まりを変えない）。
- 余裕に入らない分は入れない。入れる順は「受ける」が先、「遮る」が後。

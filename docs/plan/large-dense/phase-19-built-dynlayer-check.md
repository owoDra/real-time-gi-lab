# Phase 19（built）：動的レイヤを軽くした後の画像をユーザーが確かめる

## 開始プロンプト

```
AGENTS.md と docs/plan/README.md と docs/plan/large-dense/README.md と docs/plan/large-dense/phase-19-built-dynlayer-check.md を読み、Phase 19（built）を進めてください。Phase 18 の前後の画像（同じ画角・同じフレームの間接光、超過変動の分布図、上限 1024 であふれさせた場合）、連番、数値、費用（ms、MiB）を 1 枚の非公開の Artifact にまとめ、悪くなった所とまだ見ていない条件を先頭に書いて、私に確かめさせてください。気になる所を直し、AskUserQuestion で OK を取って終えてください。
```

## 目的

Phase 18 で動的レイヤの作り方を変えた（小片を半ボクセルから 1 ボクセル程度に。ほかは画像を変えない改良）。見た目が崩れていないかを、
ユーザーが実物で確かめる。

## 前提（[spec/30-measurements.md](../../spec/30-measurements.md) の 22 節）

- 64 物体の RC 既定の GI 3.80〜3.94 ms（作成 0.70〜0.76 ms）、超過変動と参照との誤差は前とほぼ同じ（0.00909 → 0.00914、0.4482 → 0.4482）。
- 前の画像を描くには、Phase 18 の前の実行器（コミット `c0393010` の `src/` をバンドルしたもの）を使う。64 物体は `dynBricks` 2048 で描く。
- Phase 18 で見た前後の並びは `box/in/phase18-check/`（git 管理外）に残してある。

## 決定済みの方針

- 予算と指標は変えない。技術の判断は AI が決め、ユーザーには見た目の OK だけを尋ねる。

## 確かめる決定と、その確かめ方

| 決定 | 確かめ方 |
|---|---|
| 見た目が崩れていない | ユーザーが前後の画像と連番（`--seq`）を見て OK（AskUserQuestion：OK / まだ直してほしい（どこを）） |
| 悪くなった所を隠さない | Artifact の先頭に、差が出る所（物体の手前の床、柱の縁）と、まだ見ていない条件（移動カメラ、空あり、`p1`、64 物体の DDGI）を書く |

## やること

1. 前後の画像（3 物体、64 物体、変形あり。静止カメラの間接光と最終画像、超過変動の分布図、上限 1024 の場合）と連番を描き、
   数値と費用と並べて Artifact にする（URL をここに書く）。
2. ユーザーの指摘を直して測り直し、同じ URL へ再公開する。
3. OK をもらったら、spec に「ユーザーが確かめた」と書き、このファイルを消して列の表を更新する。

## 完了条件

- ユーザーの OK を取っている。共通の完了定義（[`../README.md`](../README.md)）を満たしている。

# Phase 24（built）：多重バウンスを、ユーザーが実物で確かめる

## 開始プロンプト

```
AGENTS.md と docs/plan/README.md と docs/plan/full-dynamic/README.md と docs/plan/full-dynamic/phase-24-built-multi-bounce.md を読み、Phase 24（built）を進めてください。Phase 23 で入れた多重バウンスの前後の画像、参照（Mitsuba）との並び、連番、ちらつきの分布図、数値、費用を 1 枚のページにまとめて非公開の Artifact に公開し、悪くなった所とまだ見ていない条件を先頭に書いてください。私が気になる所を挙げたら直して測り直し、同じ URL へ再公開してください。最後に AskUserQuestion で OK を取ってください。報告は専門用語の表にせず、何が良くなり何がまだ悪いかを平易に書いてください。
```

## 目的

段階 B の出口。多重バウンスで見た目が良くなったか、動かしたときに尾を引いたり明るさが揺れたりしないかを、ユーザーが確かめる。

## 前提

- Phase 23 の結果（目安 M1〜M7）。「前」は Phase 23 の前の実行器（`build/native/rc-before.mjs`）。

## 決定済みの方針

- ページに載せる場面：`sponza`（太陽だけ、空あり）、物体 64 個、建物が変わる 2 場面、トゥーンの物体（`sponza-dyn`）、
  光源の切り替え（切り替えの前後 8 フレームの連番。RC と DDGI を並べる）、移動カメラ。
- 参照との並びは、多重バウンスの参照、RC、DDGI を同じ露出で並べる。
- 先頭に書くもの：Phase 23 で外れた目安、悪くなった所（特に、光や物を動かした後に明るさが遅れて付いてくる様子）、
  まだ見ていない条件。

## 確かめる決定と、その確かめ方

| 決定 | 確かめ方 |
|---|---|
| 屋内が明るくなり、参照に近づいた | 参照との並びと、M4 の値 |
| 動かしても尾を引かない | 光源の切り替えと、建物が変わる場面の連番 |
| 直した後に測り直す | 直すたびに M1〜M7 を測り直して載せる |
| ユーザーの OK | AskUserQuestion（OK / まだ直してほしい（どこを）） |

## やること

1. ページを作って公開する（URL をここに書く）。
2. ユーザーの指摘を一覧にして直し、同じ URL へ再公開する。
3. OK を取り、spec 30 に節を足し、spec 50 と列の表を更新する。Phase 25 のファイルの場面と設定を、この時点の構成に合わせる。

## 完了条件

- ユーザーの OK がある。共通の完了定義（[`../README.md`](../README.md)）を満たしている。

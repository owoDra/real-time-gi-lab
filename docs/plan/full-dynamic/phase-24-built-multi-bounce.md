## 直す一覧（AI が Phase 23 の画像と数値から挙げた）

1. **リーク（M6 が外れた）**：部屋の中のボリュームは暗い（画素での読み 0.25〜0.29%）。残りは場そのもののリーク 0.39% が相互反射で増えた分と見ている（未検証）。
   まずこの見立てを確かめ（部屋の中のヒットの跳ね返りだけを 0 にして測る、など）、場そのもののリークか、跳ね返りの読み方のどちらを直すか決める。
2. **手前の床の四角い斑**：ボクセルごとに跳ね返りの値を 1 つ持つため、粗い層のボクセルの形が見える。粗い層のヒットだけ読む位置で補間する、注入の
   位置をボクセルの中で表面寄りにする、などを試し、費用（M1）と並べて決める。
3. **RC が参照より暗い（偏り −17%、DDGI −6%）**：跳ね返りボリュームの照度が画素の場より低い所（覆いの穴、働かないプローブ）を確かめる。直せなければ
   spec に書いて進める。
4. DDGI は多重バウンスで 6.1〜6.5 ms。同じ 4 ms での設定の選び直しは Phase 25（ここでは直さない）。

## 決定済みの方針

- 予算と指標は変えない。RC と DDGI は同じ場面、同じ参照で測る。
- 直すたびに M1〜M7 を測り直す。GPU の時間は参照を描いていない時間帯に測る。
- 数値が目安に届いたことを、Phase 26 でのユーザーの OK の代わりにしない。

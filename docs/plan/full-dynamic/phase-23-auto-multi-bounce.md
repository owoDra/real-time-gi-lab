## 目的

段階 B の本体。今は RC も比較相手も参照も 1 バウンスで、屋内が実際より暗い。多重バウンスは見た目を最も変え、DDGI 系には
仕組み上ほぼ無料で入るので、比べ直し（段階 C）の前に両方へ入れる。

## 前提

- 段階 A の後の構成（Phase 22 は AI が確かめた。ユーザーの確認は Phase 26 にまとめる、2026-11-15 ユーザー）。GI の余裕は Phase 22 の時点の値（3.54 / 移動 3.15 ms、1 回）。Phase 21 の値（建物が波打ち物体 64 個が動く場面）：
  RC 3.57〜3.65 ms（移動カメラ 3.22〜3.28）で余裕は 0.35〜0.45 ms、多重バウンスの分（見立て 0.3〜0.5 ms、未検証）がぎりぎり入るかどうか。
  入らなければ、Phase 21 で使わなかった削る候補（gather の画素ごとの遮り判定 約 0.6 ms を、面の表裏を持つ占有で省く。未検証。リークを
  必ず測る）を多重バウンスの前に試して場所を作る。
- DDGI 線形（`ddgi-75-128-u4-g1-noadapt`）は Phase 21 の後、同じ場面で 4.6〜5.0 ms で 4 ms に入っていない（レイの区間のボクセルを以前と同じ
  大きさに保ったため）。DDGI に多重バウンスを入れても M1 は RC にだけ当てはめ、DDGI は値を書く（同じ 4 ms での選び直しは Phase 25）。
- 参照の積分器（`scripts/reference_irradiance.py`）は 1 バウンスの太陽と空だけを積分する。多重バウンスの版が要る。
- 参照は 512 spp × 2 本で各約 5 分。場面は `sponza`、`sponza-dynobj` 姿勢 0、`sponza-toon`。

## 決定済みの方針

- 作り方は AI が決める。最初の候補：ヒットした面の放射に、前のフレームの場から読んだ間接光を足す（未検証。1 バウンスに
  つき 1 フレーム遅れる。直接光と 1 バウンス目は今と同じく遅れない）。DDGI 系は自分のプローブを読み返す通常の形。
- 前のフレームを読み返す形は R1（数フレームの短い履歴は使ってよい）の範囲とする。ただし応答の目安（下の M3）を守る。
- 読み返しでちらつきが増幅しないこと（何も動かない場面で収束した後は静止時ちらつき 0）を必須にする。
- 予算と指標は変えない。参照との誤差は、多重バウンスの参照に対する値を足す（1 バウンスの参照に対する値も残す）。
- RC と DDGI は同じ場面、同じ参照で測る。一方にだけ入れて比べない。

## 目安（先に書く。結果を見てから変えない）

「今の値」は Phase 22 の時点の構成の値（Phase 22 で測り直した。品質の値は既定の sha256 が Phase 21 と同じなので Phase 21 の値）。

| # | 目安 | 条件 | 今の値 | 判定 |
|---|---|---|---|---|
| M1 | GI の GPU 時間（RC） | 段階 A の場面（建物が変形 ＋ 物体 64 個）、独立 3 回 | 3.54 / 移動 3.15（Phase 22、1 回）、3.57〜3.65 / 3.22〜3.28（Phase 21、3 回） | 3 回とも 4.0 ms 以下 |
| M2 | 静止時のちらつき | 何も動かない `sponza`、静止カメラ、ウォームアップ 60 フレームの後 | 0 | 0 |
| M3 | 光源切替への応答 | `sponza-dyn-switch<N>`、差が 50% / 10% 以下になるまでのフレーム数 | 1 / 1 | 50% は 1 フレーム、10% は 4 フレーム以内 |
| M4 | 多重バウンスの参照との誤差と偏り | 静的な `sponza` | （1 バウンスの RC を多重バウンスの参照と比べた値。このフェーズの最初に測る） | 誤差が今の値より小さく、偏りが 0 に近づく |
| M5 | 跳び（超過変動 K = 16） | `sponza-dynobj`、静止カメラ | RC 0.01063、DDGI 0.00091 | 1.25 倍以下 |
| M6 | リーク | 閉じた部屋、壁 2 cm / 10 cm | RC 0.39 / 0.12% | 1.25 倍以下 |
| M7 | 確保メモリ | M1 の場面 | RC 70.3 MiB、DDGI 91.7 | 128 MB 以内 |

M1〜M4 と M7 は必須。M5、M6 が外れたら既定には入れるが、Phase 24 のページの先頭に書いて直す。

## 確かめる決定と、その確かめ方

| 決定 | 確かめ方 |
|---|---|
| 参照が正しく多重バウンスになっている | バウンス数を 1 に絞った新しい積分器が、今の 1 バウンスの参照と参照のノイズの範囲で一致する。多重バウンスの画像を目で見る（屋内が明るくなる） |
| 以前の数値を再現する | 実装の前に M1、M5、M6 の「今の値」を再現する |
| 目安を動かさない | 上の表の判定の列が、実装の前から変わっていない |
| RC と DDGI の両方 | DDGI 0.75 m 線形でも M1、M3、M4、M5 を測る |
| 画像を先に見る | 前後の間接光と最終画像、参照との並びを数値の前に見て一覧を示す |
| GPU 時間と参照を同時に測らない | 参照を描く時間帯と GPU 時間を測る時間帯を分けたことを書く |

## やること

1. 再現。多重バウンスの参照の積分器を作り、3 場面を描く（GPU 時間の計測と重ねない）。M4 の「今の値」を測って書く。
2. RC と DDGI に多重バウンスを入れる。
3. 画像を見てから、目安を測る。
4. 還元：spec 10（指標と参照）、spec 20、spec 30（節）、spec 50、要約、Phase 24 のファイル。後のフェーズの前提が
   変わったら、そのファイルも書き直す。

その場合は既定に入れず設定のトークンで残し、Phase 24 を review に差し替える（選べる道：バウンス数や読み返す層を絞る、
多重バウンスを opt-in にして段階 C へ進む、土台を変える）。
